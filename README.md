# Daylist — Todo Manager

A lightweight, responsive task manager built with vanilla HTML, CSS, and JavaScript.

## Features

- Add tasks with high, medium, or low priority
- Optional due dates and overdue indicators
- Mark tasks complete or active
- Filter all, today's, upcoming, and completed tasks
- Search and sort tasks
- Delete individual tasks or clear completed tasks
- Progress bar and task counts
- Saves tasks in browser local storage

## Run locally

Clone or download this repository and open `index.html` in a modern browser. No build step or dependencies are required.

## Publish with GitHub Pages

1. Open **Settings → Pages** in your repository.
2. Choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. Save and wait for the deployment to finish.

## Data and privacy

Tasks are stored in local storage in the browser on the device where you use the app. They are not synchronized between devices or sent to a server. Clearing browser site data will remove saved tasks.

## Project files

- `index.html` — app structure
- `style.css` — layout and responsive styles
- `script.js` — task logic and local persistence
